# 工具栏：开始、插入

工具栏已按文末「按 Word 重排时怎么放」改过：开始、插入两个页签，点进表格后出现「表格工具」。上面「现在」一节是改之前的样子，留作对照。

只谈上方工具栏，不谈右键菜单。对照 Word 桌面中文版（Word 2019 / Microsoft 365）的「开始」和「插入」两个选项卡。加载项、听写、编辑器、联机视频、3D 模型、屏幕截图不列入。

现在工具栏只有一个页签，写着「开始」。下面的按钮按组排成一行，组名是：剪贴板、视图、字体、段落、页眉、引用、审阅、表格。Word 里这些按钮分属不同选项卡，并不都在「开始」。

## 现在「开始」页上有什么

| 组名 | 按钮 |
| --- | --- |
| 剪贴板 | 撤销、重做、新建、打开、保存 |
| 视图 | 查找、打印、缩放 |
| 字体 | 字体、字号、增大字号、减小字号、加粗、倾斜、下划线、删除线、上标、下标、字体颜色、底纹、清除格式 |
| 段落 | 左对齐、居中、右对齐、两端对齐、样式（正文 / 标题 1–3）、首行或左右缩进、行距、段前段后、大纲、表格框线 |
| 页眉 | 分页、页码、首页不同、奇偶页不同 |
| 引用 | 链接、目录 |
| 审阅 | 批注、脚注、接受修订、拒绝修订 |
| 表格 | 插入 3×3 表格、插入行、删除行、插入列、删除列、合并、拆分 |

查找点开后，替换输入框出现在工具栏下面的一条查找栏里，不在按钮组里。剪切、复制、粘贴没有工具栏按钮，只在右键和快捷键里。

## 开始

Word「开始」从左到右是五组：剪贴板、字体、段落、样式、编辑。撤销和重做在标题栏的快速访问工具栏，新建、打开、保存、打印在「文件」，缩放在「视图」和状态栏。

### 组对得上，按钮还缺

| Word 的组 | Word 有的 | 我们已有 | 差别 |
| --- | --- | --- | --- |
| 剪贴板 | 粘贴、剪切、复制、格式刷 | 功能在快捷键和右键里，工具栏没有这四个按钮 | 现在这组的名字叫剪贴板，放的却是撤销、重做、新建、打开、保存 |
| 字体 | 字体、字号、增大、减小、清除格式、加粗、倾斜、下划线、删除线、下标、上标、字体颜色 | 都有 | 下划线没有线型和颜色。没有拼音指南、字符边框、文本效果、突出显示、更改大小写、带圈字符。我们的「底」是字符底纹，不是荧光笔那种突出显示 |
| 段落 | 项目符号、编号、多级列表、减少缩进、增加缩进、两端对齐等五种对齐、行距、底纹、边框 | 四种对齐、行距、段前段后、几种固定缩进、大纲、表格框线 | 没有分散对齐、项目符号、普通编号。大纲接近多级列表，没有 Word 那种列表库。缩进是下拉里的几档，不是「减少缩进 / 增加缩进」两个按钮。没有排序，没有显示编辑标记 |
| 样式 | 样式库，正文、标题等一排可点的样式 | 下拉里只有正文、标题 1、标题 2、标题 3 | 样式塞在「段落」组里，不是单独一组 |
| 编辑 | 查找、替换、选择 | 查找，以及查找栏里的替换 | 查找现在标在「视图」组。没有「选择」菜单（全选、选择格式相似的文本） |

段落组里的框线菜单是表格框线。Word「开始」里的边框是段落边框；表格框线在点进表格之后的「表格工具」里。

### 不该留在「开始」

| 现在的按钮 | Word 放在 |
| --- | --- |
| 撤销、重做 | 快速访问工具栏 |
| 新建、打开、保存 | 文件 |
| 打印 | 文件 |
| 缩放 | 视图 |
| 分页、页码、首页不同、奇偶页不同 | 插入 → 页眉和页脚；首页不同、奇偶页不同还在页眉页脚设计里 |
| 链接 | 插入 → 链接 |
| 目录 | 引用 |
| 批注、接受修订、拒绝修订 | 审阅。较新的 Microsoft 365 把「新建批注」也放进插入，接受和拒绝仍在审阅 |
| 脚注 | 引用 |
| 插入表格 | 插入 → 表格 |
| 插入行、删除行、插入列、删除列、合并、拆分 | 表格工具 → 布局，只有点在表格里才出现 |

## 插入

Word「插入」从左到右是：页面、表格、插图、链接、页眉和页脚、文本、符号。我们没有「插入」页签，相关按钮散在现在的「开始」页上。

| Word 的组 | Word 有的 | 我们已有 | 差别 |
| --- | --- | --- | --- |
| 页面 | 封面、空白页、分页 | 分页 | 没有封面、空白页 |
| 表格 | 格子盘选行列，再插入表格；另有绘制表格、快速表格 | 一个按钮，固定插入 3×3 | 插行、删行、插列、删列、合并、拆分已能做，但 Word 不把它们放在插入页上常驻 |
| 插图 | 图片、形状、图标、SmartArt、图表 | 打开的文档能显示图片、形状、文本框；文本框里可以打字 | 工具栏不能插入图片，也不能改大小和环绕。不能从工具栏插入形状。SmartArt 不做 |
| 链接 | 链接、书签、交叉引用 | 设置链接、取消链接 | 没有书签、交叉引用 |
| 页眉和页脚 | 页眉、页脚、页码 | 页码、首页不同、奇偶页不同。双击页眉页脚区域可以进去改 | 没有「页眉」「页脚」两个入口按钮。首页不同、奇偶页不同在 Word 里要进页眉页脚之后才出现 |
| 文本 | 文本框、艺术字、首字下沉、日期和时间、对象 | 已有文本框可以编辑 | 不能新插文本框，没有艺术字、首字下沉、日期和时间、对象 |
| 符号 | 公式、符号 | 打开的公式能显示 | 不能插入公式，也不能改公式内部；没有符号面板 |

目录、脚注、批注、接受修订、拒绝修订都不是插入页的常驻内容。目录和脚注属于「引用」，批注和修订属于「审阅」。

## 按 Word 重排时怎么放

先只动「开始」和「插入」。按钮能做的事就搬过去；做不到的不放空按钮。目录、脚注、批注、修订先从「开始」拿下来，等「引用」和「审阅」页再放回去。打印和缩放不属于这两页，先留在标题栏一侧，页签仍叫视图的位置以后再单开。

### 开始

| 组 | 放上的按钮 | 说明 |
| --- | --- | --- |
| 剪贴板 | 粘贴、剪切、复制 | 沿用现在的剪贴板。格式刷先不做 |
| 字体 | 上排字体、字号、增大减小、清除格式；下排加粗、倾斜、下划线、删除线、下标、上标、底纹、字体颜色。色板下的「其他颜色」打开标准色块和自定义色面，可填 RGB / HSL | 拼音、字符边框、文本效果、大小写先不做 |
| 段落 | 上排大纲和缩进，下排四种对齐、行距、段前段后 | 表格框线移出这一组。项目符号、分散对齐、排序先不做 |
| 样式 | 正文、标题 1、标题 2、标题 3 | 从段落组里拆出来 |
| 编辑 | 查找、替换 | 替换仍用现在的查找栏 |

撤销、重做、新建、打开、保存留在页签那一行的右侧，当作快速访问，不再占用「剪贴板」这个名字。

### 插入

| 组 | 放上的按钮 | 说明 |
| --- | --- | --- |
| 页面 | 分页 | 封面、空白页先不做 |
| 表格 | 表格 | 仍先插入 3×3。行、列、合并、拆分不放在这一页常驻 |
| 插图 | 先空着 | 插入图片、改大小和环绕还没做，不放按钮 |
| 链接 | 链接 | 书签、交叉引用先不做 |
| 页眉和页脚 | 页码、首页不同、奇偶页不同 | 页眉、页脚入口先沿用双击进入 |

文本框、公式、符号先不放。点在表格里时要出现的「表格工具」（插删行列、合并拆分、表格框线）另做，不塞进插入页。
